# UI/UX Pro Max & Design Taste Skill

Use this skill whenever creating or modifying front-end user interfaces, dashboards, components, or layout structures.

## 🎯 Design Directives & Taste Checklist

1. **Aesthetic Tone**:
   - High-density, professional tech SaaS (Deepgram Studio / Linear / Vercel pattern).
   - Obsidian dark mode canvas (`#0a0a0c`), graphite card containers (`#111114`), crisp 1px borders (`border-zinc-800/80`).

2. **Typography Rules**:
   - Clean sans-serif (`font-sans`) for headings and readable titles.
   - Monospace (`font-mono text-[11px] text-zinc-500`) for all tags (`nicho • pilar • formato`), timestamps (`Created Jun 12`), item counters `[5]`, and shortcuts `⌘K`.

3. **Responsive Grid Architecture**:
   - Use `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-4` for card grids.
   - Never use static max-width wrappers (`max-w-[1550px]`) that leave empty side gaps on large monitors.
   - Provide drawer toggle (`isMobileSidebarOpen`) for viewports below 1024px.

4. **Anti-Slop Guidelines (Impeccable & Taste-Skill)**:
   - Eliminate nested cards-in-cards padding bloat.
   - Avoid generic uncurated gradients or overused default Inter font styling without monospace accents.
   - Keep status indicators clear and color-coded (`● Active` in emerald, `● Draft` in purple, `● Ready` in amber).
